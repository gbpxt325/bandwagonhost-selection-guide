## 一、搬瓦工 BandwagonHost 是什么？为什么这么多人选它

搬瓦工 BandwagonHost 隶属于加拿大 IT7 公司，这家公司成立于 2004 年，做 VPS 已经有二十年了。二十年是什么概念？很多当年一起起步的小商家早就不在了，搬瓦工还活着，而且越活越好，机房越开越多，这说明它的稳定性和运营能力是经得起时间考验的。

搬瓦工最核心的卖点其实就一句话：**中国优化线路做得特别扎实**。它最早是靠便宜 VPS 起家，后来陆续接入了 CN2 GT、CN2 GIA-E、CN2 GIA 等电信高端回程线路，以及联通、移动的优化线路，让国内用户访问海外服务器的延迟和丢包率都明显降下来。如果你做过建站、科学上网、跨境业务、远程办公、游戏加速之类的事情，大概率都绕不开它。

## 四、CN2 GT、CN2 GIA-E、CN2 GIA 到底有什么区别

这一节可能是整篇里最该认真看的部分。搬瓦工之所以贵、之所以被推崇，核心就在线路。但线路种类一堆名词，新手很容易懵。我用最简单的方式讲一遍。
